# Readlane identity

![Readlane app icon](../assets/logo.svg)

## The idea

Folded pages create an open doorway. The central negative space suggests a lane into another world, while the two sides retain the warmth of a bound book.

## Color

| Role | Color |
| --- | --- |
| Primary | `#a66859` |
| Deep tone | `#593937` |
| Accent | `#e8bd7a` |

## Assets

- `assets/logo.svg`: master app tile; vector, no external fonts or images.
- `assets/brandmark.svg`: transparent symbol for coordinated brand surfaces.
- `assets/icon-192-v2.png` and `assets/icon-512-v2.png`: app installation and home-screen icons.
- `assets/icon-maskable-512-v2.png`: full-bleed icon with its core symbol inside the maskable safe area.
- `assets/banner.svg`: repository cover with the same identity.

Keep the symbol’s proportions, preserve its negative space, and avoid adding text inside the icon. The interface uses the master tile directly; PNGs are rendered from the same SVG.
